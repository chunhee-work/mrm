---
name: photo-center-crosshair-rule
description: User rule — a Merimen photo's item name refers to the part at the CENTRE of the image (crosshair of vertical + horizontal centre lines)
metadata:
  type: feedback
---

When naming / checking a case photo, mentally draw a vertical and a horizontal line through the middle of the image; the part under that centre point is the item the caption names (user, 2026-10-11).

**Why:** photos often show several parts; adjusters frame the named part in the middle, so edge content is context only.
**How to apply:** (1) when Claude looks at a photo, describe/name only what sits at the crosshair; (2) draw the crosshair on review/teaching sheets sent to the user; (3) photo model: train/infer with centre emphasis (centre crop alongside the full frame). Related: [[photo-naming-two-step-jev]].

**Taught pair — Boot Floor vs Rear Wheelhouse (user drawing on teach sheet #1, 2026-10-11):** Boot Floor = the big floor panel with stamped ribs / raised reinforcement ridges running across it (fills the centre of the photo). Rear Wheelhouse = the curved arch bulge at the side/corner of the boot (small area at the photo's edge). Photo centre was on the ribbed floor → caption Boot Floor, consistent with the crosshair rule.

**Labeling tool (2026-10-11):** https://claude.ai/artifact/BS7auqjnbs6Y7SZvzL4Vnh — user marks the centre part + draws named regions on photos the model got wrong. db collections: `tasks` (t01..t40: img asset url, merimen caption, model guess top-3, cid, seq) and `labels` (doc id = task id: {status done|skip, center, regions:[{name,color,pts normalized x,y,...}], note}). Read `labels` with ArtifactData to learn; add new batches by uploading assets (Artifact asset:true) + writing `tasks` docs. The 3D page is set aside (user: no longer needed).

**Taught — Rear Bumper vs Spoiler vs Moulding (user, 2026-10-11):** Rear Bumper = the main bumper cover itself. Rear Bumper Spoiler = an extra piece mounted onto the bumper, always at the LOW part (lower lip/diffuser); not every car model has one, so if the bumper has no separate lower piece there is no spoiler. Rear Bumper Moulding = the finisher strip on the UPPER part of the bumper, a decorative highlight trim (chrome/gloss strip).

**Taught — Rear Chassis Member LH vs RH (user, 2026-10-11; corrected same day):** decide the side ONLY by the tyres: in underbody photos the tyre at the far right of the photo is RH, the tyre at the far left is LH. How it looks: a chassis member is a long panel running in a straight line (a straight beam along the car underside). The earlier "exhaust pipe side = RH" rule was WITHDRAWN by the user — do not use the exhaust to decide.

**Zoom-out / zoom-in check (user, 2026-10-11):** when the crosshair lands on a boundary between two parts (e.g. Grille Front vs Headlamp LH), look at the neighbouring photos of the same case — the zoom-out context shot and the zoom-in detail shots — to see which part the sequence is about, then name it. Example: labeling-tool photo with Merimen "Grille Front", user marked the centre as Headlamp LH (centre sat on the grille/headlamp edge).

**Model-dependent names (user, 2026-10-11, refined):** only PERODUA cars split the front structure into separate names — Front Panel Upper, Fender Inner, Front Crossmember, Front Panel Lower. EVERY other make calls all of these one part: "Front Panel Assembly". Rear Lamp Inner/Outer also depends on the car model (split lamps vs single) — build/keep a per-model table (photo_train/lamp_models.json → model ↔ split/single) so naming never guesses. Vehicle model per case comes from dsp_details "Vehicle Model:" (works with caseid only, no extid).
**Side from the last zoom-out (user, 2026-10-11):** for a zoomed-in photo, go back to the most recent zoom-out shot before it in the sequence — the adjuster shoots the zoom-ins from that same viewpoint/side. Read LH/RH (and which part) from that zoom-out photo (e.g. which tyre/lamp/door is visible), then carry it to the following close-ups.

**From labeling batch 1 (40 photos the model "got wrong", 2026-10-11):** the user confirmed the MODEL was right on 18 and Merimen's caption was a typo/wrong on many ("i type wrong in Merimen") → Merimen captions are noisy; user answers saved as photo_train/user_corrections.json (cid:seq → name) and applied by build_big.py. Cues the user gave: Boot Floor = steel; Spare Wheel Well = plastic; Rear Wheelhouse = only the left-side part with the strength line; Rear Panel Inner Trim = plastic; Boot Lid Hinge = steel; Door Aperture Weatherstrip = black plastic/rubber strip; Rear Bumper Sensor = a circle; Runningboard Panel = the horizontal-line part at the bottom; Quarter Panel = a big panel; Bonnet Hinge = a different layer; Door Front vs Rear: look for the outer handle release at the rear of the door; Boot Lid Striker vs Lock often mistyped (centre was the Lock); INSPECTION DISC photo → Road Tax; sometimes the shot is a bit off the middle line; always check the first LH/RH view shot before the zoom-ins.

**Workflow rule (user, 2026-10-11):** whenever the user says a photo name is wrong, or Claude is unsure, put those photos into the 部位标注台 (labeling tool) as a new batch for the user to mark; then read `labels` and absorb. Claude reviews the rest itself with the learned rules and only sends the unclear ones.

Adjusters are inconsistent (e.g. HONDA CITY 2014 On: 5 split / 14 single), so mixed models need the user's confirmation before treating as rule.

**Hand rule (user, 2026-10-11):** when a hand is holding, lifting or pointing at something in the photo, THAT part is the named item — it overrides the crosshair centre.
**Labeling batch 2 (t41–t50, 2026-10-11):** of 10 photos Claude was unsure about, the MODEL was right on 7, Merimen on 2, neither on 1 → when the model's pick matches what sits at the crosshair, prefer the model over a conflicting Merimen caption (adjusters mistype a lot). New cues: a windscreen-from-outside shot among the first few photos is usually Interior View, BUT if the shot is about the road tax — a small paper/disc look (printed slip) at the centre — it is Road Tax (user: "road tax is a paper look"); for rear-impact cars the first straight-from-behind shot = "Rear View" (no Left/Right); hand holding/pointing = that item (Quarter Liner LH example).
**Bumper brackets (Claude's description, user confirmed "you are right", 2026-10-11):** Rear Bumper Bracket LH/RH = black plastic bracket hidden behind the bumper corner, holding the bumper end to the body (seen when the bumper is removed or its corner lifted). Bracket Upper = horizontal strip along the bumper's top edge under the rear lamp. Bracket Side = vertical bracket at the bumper side next to the rear wheel arch / quarter panel. Tell them apart by position and direction (under lamp + horizontal = Upper; by the arch + vertical = Side).
**Chassis member side via the boot floor (user, 2026-10-11):** the boot floor has a concave-down recess (the spare wheel well — a separate part). The rear chassis members run along either side of it, so use where the recess sits in the photo to tell which side (LH/RH) the chassis member at the centre is on; combine with the far-left/far-right tyre rule.
**Runningboard Spoiler (user, 2026-10-11):** same concept as Bumper vs Bumper Spoiler — Runningboard Panel is the main metal sill; Runningboard Spoiler is an extra plastic piece attached onto it (lower/outer skirt), and only some car models have one. No separate add-on piece on the sill → no spoiler, name it Runningboard Panel.
