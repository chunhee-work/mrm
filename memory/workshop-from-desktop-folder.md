**How to apply:** When the user names a case, find its folder under the matching workshop folder on Desktop, read the PDF for claim data, and in Merimen pick the workshop matching the parent folder name (use the Lookup search box, type the folder name, pick the match).

**A case may be SPLIT across several PDFs (2026-07-03).** A case folder can contain multiple PDFs — read ALL of them. Document/file naming convention (matches Merimen's Documentation list labels RC/INS/P.REPORT/JPJ SEARCH):
- **RC** = Sijil (JPJ Sijil Pemilikan Kenderaan — OUR client's vehicle ownership cert).
- **INS** = OUR customer's own insurance.
- **P.REPORT** = police report(s).
- **JPJ SEARCH** = the **对方保单 = the AT-FAULT party's insurance/policy** (the vehicle-detail/I-SEARCH page for the party we claim against). So the "JPJ SEARCH <plate>.pdf" file holds the at-fault insurer + policy no + period + coverage. e.g. for TCL730 read `~/Desktop/sinar/JPJ SEARCH TCL730.pdf` for the at-fault policy.
- **⚠️ JPJ SEARCH is USUALLY the last page — but NOT ALWAYS. READ THE WHOLE PDF (corrected 2026-07-16 after I wrongly skipped 4 cases).** The at-fault JPJ/I-SEARCH is the insurance-search page that names a **DIFFERENT insurer/plate than our own client** (our client's own RC/insurance is one thing; the OTHER, different insurer/JPJ-search in the bundle = the at-fault party we claim against). It can be on any page. **Match the plate on that JPJ-search to the police "disalahkan" plate; the plate/name must match.** If the JPJ-search image is unclear, cross-check the plate against the police report — the words must match.
- **⛔ NEVER skip a case as "no at-fault JPJ / incomplete" just because the last page isn't a JPJ-search or the folder looks mixed. FIRST read the ENTIRE PDF and look for the second/different insurer or I-SEARCH.** (2026-07-16: I skipped BMB8496 [at-fault CDR7670/MSIG], STA8148A [TDB4752/Zurich], VMJ6957 [TCW3337], VNL7354 [BHD2546/Allianz] as "incomplete" — but every one had the at-fault JPJ-search inside the PDF, just not obvious on the last page. That was a real mistake; don't repeat it.)
- **⚠️ TWO STEPS TO LOCK THE AT-FAULT PARTY — never skip (this is how TDB1847 went wrong, 2026-07-08):** (1) Read the police **Keputusan Penyiasatan** — it names the **disalahkan (at-fault) plate**. (2) The at-fault insurer = the **JPJ SEARCH (last page)** for **that exact plate**. The disalahkan plate and the JPJ-search plate MUST match. If any insurance doc in the folder names a DIFFERENT plate, it is **misfiled from another case → ignore it**, don't use it. Never pick the at-fault party by "which doc looks more complete" — pick by (structural rule: last page) + (proof: police disalahkan plate).

**PDF size rule (CORRECTED 2026-07-07 by user): only compress if a PDF is OVER 5 MB.** Merimen's upload limit is ~5 MB. **Files ≤ 5 MB upload as-is — do NOT compress them.** Only when a file is **> 5 MB**, compress it to under 5 MB and save. (Supersedes the earlier "compress anything > 3 MB down to < 3 MB" — that over-compressed files that were fine.) Ghostscript/poppler are NOT installed on this Mac — use the **PyMuPDF** script `scratchpad/compress_pdf.py "<path>"` (installed via `pip install PyMuPDF`). Method: re-render each page to JPEG and rebuild the PDF, adaptively dropping DPI (140→96) until <3 MB; keeps document text legible at ~120 DPI. Saves alongside the original as `<name>_compressed.pdf`. (Verified 2026-07-04: a 17 MB scan → 2.68 MB at DPI 120 / q62.) The Read tool itself handles big PDFs fine — the size limit is only about the Merimen upload.

**Workshop Lookup — WORKING METHOD (2026-07-02):** On the Create Motor Claim form, the Workshop field (`ddlbREPCOIDTEXT` display + `ddlbREPCOID` hidden COID) is set via a **Lookup...** popup (`MTRworkshopbtn`). 
- Claude CANNOT open the popup (synthetic clicks are popup-blocked; only a real user click opens it). So ask the USER to click **Lookup...** once.
- Once open, the popup is a controllable tab (about:blank, title "Find..." → "Company List"). Claude DRIVES it via chrome-control with that tab_id: (1) set the single `input[type=text]` (the KEYWORD box) to the workshop name e.g. "extreme auto" + fire input/change; (2) click the **Search** button; (3) click the result `<td>` whose text contains the workshop (e.g. "Motor Repairer - Extreme Auto Car Care - Kuantan") — a delegated handler sets `ddlbREPCOIDTEXT` + `ddlbREPCOID` on the opener form and closes the popup.
- The direct XML endpoint search (`&S=`/`&KEYWORD=` GET/POST) does NOT filter server-side, so don't bother — drive the popup UI instead.
- **After the popup selection, re-set `ddlbDAMTYPE` = "Collision"** — the re-render on selection can clear the Damage Type dropdown; verify/re-set it.
