User review of sinar batch (2026-10-17), "all this keep in memory":

1. **Every item named in the photo artifact must be in the estimate.** Missing from the catalogue → add a manual row (FB438 missed Bumper Front Fog Lamp LH; the user added it at 763.00).
2. **Quantity = the blue number button at the row's left** (click it to change 1 → 2). Paired items (sensors "Rear LH & Rear RH", hinges ×2…) must get qty 2. The user said "u missed all": check qty on every case.
3. **Bumper Rear Sensor always needs the Comment "Rear LH & Rear RH"** (the text line under the part name), manual rows included (JNC9717 manual sensor row had none). Sensor count rules: [[merimen-step2-estimate-detail-fill]].
4. **Every estimate with a bumper must have Bumper Clips** (Saga 2022 MDP5464 had none). If the matcher can't find "Bumper Clips", search the catalogue for clip/fastener items; qty 15.
5. **Door replaced → select ALL of that door's items**, e.g. Saga 2022 Door Rear RH set: Door Check Strap Rear RH, Door Glass Weatherstrip Outer Rear RH, Door Lock Rear RH, Door Rear Aperture Weatherstrip, Door Rear Hinge Lower RH, Door Rear Hinge Upper RH, Door Rear RH, Door Striker, Door Trim Board Finisher Rear RH, Door Window Regulator Rear RH, Weather Sheeting Door. Same idea for Door Front.
   **Door Front → also Door Mirror (same side). Door Rear only → no mirror.**
6. **Quarter Panel Outer → also Quarter Panel Liner (same side).**
7. **Labour "Door Back" = Boot Lid & Tailgate**: tick Door Back (N) when the boot lid/tailgate is replaced. Example Rear Compartment ticks for a rear hit: Boot Floor N, Chassis Member Rear Section Rear LH/RH R, Door Back N, Fuel Tank R&R N, Suspension Rear R&R N.
8. The user fixed the labour I missed in Merimen. Read each case's final labour ticks back, compare with what I set, and learn from the difference.

9. **Shock Absorber Front → also Suspension Crossmember Front; Shock Absorber Rear → also Suspension Crossmember Rear** (user 2026-10-17; the user added Suspension Crossmember Front to MDP5464). "Bumper Rear Shock Absorber" is a bumper part, not suspension.
10. **Labour the user added on MDP5464** (Saga 2022, front-RH hit, after mine + labourfill), all R:
   - Front Panel replaced → Chassis Member Front End Closing LH + RH, Chassis Member Front LH + RH Front Section
   - Door Rear → Door Glass Rear Window RH, Door Glass Quarter Rear RH
   - Door Front → Door Glass Front Window RH, Door Mirror RH (tts)
   - Fender Front → Fender Front Inner Upper RH
   So: tick the glass/mirror R&R of every replaced door, and the closing/front-section members on both sides when the front panel is replaced.
11. **Manual Bumper Clips** when the catalogue has none: qty 15 × 10.00 (the user's own MDP5464 row; most price-data rows are 10.00). Missing Quarter Panel Liner on WWH2330 (Nissan): manual 325.00 each, the median of Nissan rows.

**Why:** these are the gaps the user found after I reported the batch done.
**How to apply:** apply in Step 2 for every case. Companion rules: [[estimate-companion-parts-rule]].
