# 10 · Car models: which items each model has, and what they are called

Read this when a case's model is known (photo naming, step 3) and again before Select Parts (step 9).
It records 冷门 (rare) items, Inner/Outer layouts and the catalogue's own name for a photo name, per model.
**After every case, add what you learned** (user 2026-10-23): new rare items, Inner/Outer, catalogue names, items the
catalogue does not have (manual row + price used). Newest entry wins.

Format per model: Merimen model text · case(s) · photo name → catalogue item (or "manual").
