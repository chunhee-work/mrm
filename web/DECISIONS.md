# web/ decisions

- Stack as in plan.md §3: Next.js 15 App Router, Drizzle on Neon (neon-http), Better Auth (email+password, verification, reset), Resend, Vercel Blob.
- Blobs are uploaded with `access: "private"` under `<orgId>/…` (files hold NRIC/addresses). The upload route rejects paths outside the caller's org.
- Org is created at sign-up by a Better Auth `user.create.after` hook (neon-http has no transactions; two inserts).
- Password minimum 10 chars; email verification required before login.
- `src/db/index.ts` is lazy so `next build` works without secrets; a localhost DATABASE_URL uses node-postgres (tests only).
- Migrations: `drizzle/*.sql` (generated by drizzle-kit), applied by `npm run db:migrate` (tracks `_migrations`).
- Stage-2 tables (merimen_connections, jobs, usage, credits) are created now so the schema is stable; nothing uses them yet.
- Privacy/terms pages are placeholders; owner supplies legal text.
- Brand name: **Autopilotclaim** (owner, 2026-11-14; domain autopilotclaim.com bought, DNS on Vercel). Mail is sent from `EMAIL_FROM="Autopilotclaim <noreply@autopilotclaim.com>"` once the Resend domain is verified (until then use the Resend test sender). The test sender only delivers to the Resend account owner's own email address, so only that address can complete sign-up in production for now.
- No domain will be bought for now (owner, 2026-11-14): deploy on the default *.vercel.app URL.

## Smoke test account (2026-11-14)
- Pattern copied from chunhee00/oeru-onhand (`staging` branch, docs/smoke.md): real browser, every page in EN/BM/中文 on laptop and phone, target guard (only our own site or localhost), PASS/WARN/FAIL report. Unlike oeru-onhand (signed-out only; its smoke account was cancelled), Autoclaim has login, so it also logs in.
- Account: `smoke-tester@autoclaim.invalid`, email pre-verified (no mail needed), own empty org. Created with `scripts/seed-smoke-user.ts` (idempotent, touches only that email). Password lives only in the CI/local env `SMOKE_PASSWORD`, never in the repo.
- Run: `SMOKE_PASSWORD=… node scripts/smoke.mjs https://autoclaim-web.vercel.app` (needs Playwright). It writes nothing, uploads nothing.
- Not done yet: a GitHub Actions workflow (needs `SMOKE_PASSWORD` as a repo secret, and a workflow file the owner approves).
